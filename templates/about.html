About todoxt

A small multi-user todo app that shows what xtemplate can do with almost no application code — just templates, SQL, and Caddy. Multi-list, per-user isolation, and live SSE go beyond a classic TodoMVC clone.

  • File-based routes and method routes defined in HTML templates
  • SQLite via the sql provider (per GitHub user)
  • Multiple lists with clean REST URLs: /list/{slug}/{id}
  • Live multi-tab sync with the in-process bus + SSE (per list)
  • htmx 4 for progressive enhancement without a SPA
  • Auth in Caddy (GitHub OAuth via caddy-security); templates only see identity headers

Browser form posts are protected by xtemplate’s default Go CrossOriginProtection (CSRF). Production adds trusted_origins in the Caddyfile — no app-level CSRF tokens.
